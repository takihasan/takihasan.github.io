# Taki Hasan Rafi Academic Website

This is a lightweight, traditional academic website that can be hosted directly with GitHub Pages. It intentionally uses a plain white background, Times-style serif text, compact spacing, thin section rules, and standard lists.

## Add your photo

1. Choose a square or portrait JPG photograph.
2. Rename it to `profile-photo.jpg`.
3. Save it inside the `assets` folder as `profile-photo.jpg`.
4. In `index.html`, change:

   `assets/profile-placeholder.svg`

   to:

   `assets/profile-photo.jpg`

Recommended photo size: at least 600 × 600 pixels.

## Add your profile links

Open `index.html` in a text editor and find the `profile-links` section. Replace each `#` with your email, Google Scholar, GitHub, and CV URL.

## Preview

Double-click `index.html` to open it in a browser.

## Upload to GitHub

Upload `index.html`, `styles.css`, `README.md`, and the `assets` folder directly to your repository.
